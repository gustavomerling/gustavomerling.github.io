# Natural Pixels

Element sandbox inspired by Powder Game — soil, water, seeds and more, interacting on their own.

- Design doc: [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)
- Live: https://gustavomerling.github.io/natural-pixels-game/dist/

```bash
npm install
npm run dev     # local dev server
npm run build   # type-check + build into dist/ (commit dist/ to deploy)
npm run lint
```
