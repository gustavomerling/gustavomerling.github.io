## 🚀 Projetos em Destaque

### 💰 App de Finanças Pessoais (`app/`)
Um gerenciador de finanças pessoais moderno construído com React e TypeScript. Permite controlar receitas, despesas e visualizar gráficos de evolução financeira.

**Tecnologias:** React, TypeScript, Vite, CSS Modules

### 🎮 Perpetual Break (`perpetual-break/`)
Um jogo de arcade estilo Breakout/Pong em desenvolvimento. Projeto experimental para explorar mecânicas de jogo e física.

**Tecnologias:** React, TypeScript, Canvas API

### 🧩 Jelly Tetris (`jellytetris/`)
Uma variação divertida do clássico Tetris com elementos "jelly" - blocos que se movem com física suave e efeitos visuais satisfying.

**Tecnologias:** JavaScript, Matter.js, HTML5 Canvas
