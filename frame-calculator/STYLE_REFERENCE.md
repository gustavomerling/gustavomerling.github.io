# Design Reference: Encantalar

Referência visual e de estilo inspirada no site https://encantalar.com.br/

## Visão Geral
Site de decoração corporativa permanente. Design limpo, elegante, minimalista com foco em:
- Botanical theme (verde/plantas)
- High-quality imagery
- Clear hierarchy
- Clean typography
- Professional, sophisticated aesthetic

## Design Tokens Identificados

### Cores
- **Primary Green**: Tom verde corporativo (botanical)
- **Gold/Accent**: Para ratings e destaque (5,0 no Google)
- **White**: Background principal
- **Dark/Charcoal**: Texto e elementos secundários
- **Subtle Grays**: Para backgrounds secundários

### Typography
- **Sans-serif**: Fonte moderna e limpa (presumível: Inter, Montserrat ou similar)
- **Font Weights**: 400 (regular), 600-700 (bold)
- **Heading Sizes**: Hierarquia clara (h1 grande, descrescente)
- **Body Text**: Legível, generoso em line-height

### Spacing
- Vertical rhythm consistente
- Gaps generosos entre sections
- Padding interno bem definido
- Mobile-first approach

### Components
- Portfolio cards com subtle shadows
- CTA buttons (WhatsApp primary)
- Logo carousel
- Testimonials section
- Image gallery

## Inspirações para Frame Calculator

1. **Elegância minimalista** — design clean sem excesso
2. **Botanical/Natural** — cores terrosas, verdes, madeiras
3. **High-quality previews** — imagens/renders profissionais
4. **Clear CTAs** — botões direcionados (Adicionar ao Orçamento)
5. **Trust signals** — ratings, quantity feedback
6. **Mobile-friendly** — WhatsApp como CTA secundária
